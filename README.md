# Rockfort Metal Coating – New Website

A clean, SEO-friendly static website based on the existing rockfortindustries.com site and company details.

## Pages
- index.html – Homepage
- about.html – Company overview
- services.html – Detailed services (including fabrication & machining)
- gallery.html – Placeholder for before/after photos
- contact.html – Contact details

## How to use
1. Download the entire `rockfort-new-website` folder.
2. Upload it to any web host (or open index.html locally to preview).
3. Replace gallery placeholders with real photos.
4. Later, this content can be migrated into WordPress if preferred.

All content is ready to copy-paste into your current WordPress site as well.
